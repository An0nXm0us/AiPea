# Eddie - Educational App

Eddie is a comprehensive educational Android application that provides students with tools for reading, note-taking, calendar management, and AI-powered assistance.

## Features

### 📚 Textbook Reader
- Support for EPUB and PDF formats
- Text highlighting and search functionality
- Local file management
- Online book search and download

### 📝 Notes Management
- Create, edit, and delete notes
- Cloud synchronization
- Organized note listing

### 📅 Calendar & Scheduling
- Event creation and management
- Event categorization (Classes, Assignments, Exams, Personal)
- Filter events by type
- Local and cloud storage

### 🤖 AI Assistant
- Chat with Gemini AI
- Conversation history
- Multiple chat sessions
- Real-time responses

### 🔐 User Authentication
- Secure login and registration
- Session management
- Password reset functionality

## User Manuals

### Getting Started
1. **Registration**: Create a new account or login with existing credentials
2. **Navigation**: Use the bottom navigation bar to switch between features
3. **Profile**: Access user settings and logout from home screen

### Textbook Usage
1. **Search Books**: Use the search bar to find textbooks
2. **Download**: Tap download icon to save books locally
3. **Read**: Open downloaded books for reading
4. **Highlight**: Long-press text to highlight important content
5. **Search**: Use in-book search to find specific content

### Notes Management
1. **Create Note**: Tap the floating action button to add new notes
2. **Edit Note**: Tap any note in the list to modify it
3. **Delete Note**: Swipe or use delete option to remove notes
4. **Auto-save**: Notes are automatically synchronized

### Calendar Features
1. **View Events**: See all scheduled events for selected date
2. **Add Event**: Use the "+" button to create new events
3. **Filter**: Use dropdown to filter events by type
4. **Categories**: Organize events as Classes, Assignments, Exams, or Personal

### AI Assistant
1. **Start Chat**: Tap "New Chat" to begin conversation
2. **History**: Previous chats are saved automatically
3. **Multiple Sessions**: Create separate chats for different topics
4. **Real-time Responses**: Get instant AI-generated answers

## Technical Specifications

- **Platform**: Android
- **Minimum SDK**: API 21 (Android 5.0)
- **Architecture**: MVVM with Repository Pattern
- **Database**: Room Database with Firebase integration
- **File Support**: EPUB, PDF
- **AI Integration**: Google Gemini API
